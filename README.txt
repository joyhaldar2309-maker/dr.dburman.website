# Dr. D Burman Website

## GitHub Pages
Upload all files and folders in this package to the root of your GitHub repository:
- index.html
- manifest.json
- sw.js
- assets/logo.png
- assets/doctor.png

Then enable GitHub Pages from the repository's Settings > Pages.

The site is responsive for mobile and desktop. The appointment form opens WhatsApp with the entered details. The PWA files allow supported mobile browsers to offer an "Install app" / "Add to Home Screen" experience when served over HTTPS (such as GitHub Pages).
